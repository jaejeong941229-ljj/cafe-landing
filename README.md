# cafe-landing

가상의 카페 "모닝브루"의 간단한 랜딩 페이지 예제 프로젝트야.
HTML과 CSS만으로 만들었고, 별도 설치나 빌드 없이 브라우저에서 바로 열 수 있어.

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 페이지 본문 (첫 화면, 대표 메뉴, 카페 소개, 오시는 길) |
| `style.css` | 디자인 스타일 (모바일 화면 대응 포함) |

## 사용법

`index.html` 파일을 더블클릭해서 브라우저로 열면 돼.

## 수정 방법

- 가게 이름, 메뉴, 가격, 주소, 영업시간은 `index.html`에서 바꿔.
- 색상과 레이아웃은 `style.css`에서 바꿔.
